# 宇总·财会实战 · 社区开源版（yuzong-finance-skills）

> 财会岗位工作流的**讲解、通用方法框架与脱敏示例**。
> **开源 ≠ 送核心**：本仓库教你“怎么干”的方法论与示例；真正值钱的“校准过的判定口径 + 全套出活模板 + 专家陪跑”在 WorkBuddy 付费获取。

## 这是什么

面向财会从业者（会计 / 出纳 / 成本 / 税务等岗位）的开源技能集合。每个技能是一个可直接放入 [WorkBuddy](https://www.workbuddy.cn) 运行的技能包（`SKILL.md` + `references/`），你可以照着学工作流，也可以直接调用。

本仓库的定位是 **Open-Core 的“开源层”**：用免费内容做引流、备份与共建，把付费转化留给 WorkBuddy 侧的闭源核心。

## 开源范围 vs 闭源范围

| 本仓库（免费公开，CC BY-NC 4.0） | WorkBuddy 付费（闭源核心，永不公开） |
| --- | --- |
| 岗位工作流的**讲解**、通用方法框架 | **校准过的**风险判定口径（如科目风险红线数值） |
| 脱敏的**示例**模板（不含真实口径） | 全套**出活**模板（带公式、带口径、可直接交付） |
| 教育性内容、通用避坑清单 | 专家陪跑 agent（月结顾问 / 出纳顾问等） |
| 更新日志、Issues / PR 共建入口 | 持续校准更新与一对一支持 |
