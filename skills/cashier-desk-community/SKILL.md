# 出纳资金日清与余额调节（社区版）

> 本文件是**开源讲解版**，只给“方法论 + 脱敏示例”，不提供校准过的风险判定阈值与全套出活模板。
> 需要可直接交付的余额调节表 / 现金盘点表 / 资金日报与宇总判定口径，请使用 WorkBuddy 付费版。

## 一、出纳每天在干什么（工作流）

1. **收付款**：根据审批后的单据办理现金 / 银行收付款，当场开票或取得回单。
2. **记日记账**：逐笔登记现金日记账、银行存款日记账（谁经手、何时、金额、对方、事由）。
3. **日清**：当日账面现金与保险柜实存核对；当日银行收支与网银 / 银行流水勾对。
4. **银行对账**：拿企业银行存款日记账 vs 银行对账单，找出“未达账项”。
5. **余额调节**：编制银行存款余额调节表，证明“企业账”和“银行账”只是时间差，调节后必相等。
6. **编资金日报**：汇总当日收支、余额、大额异动，报给老板 / 财务主管。

## 二、银行余额调节通用框架（四类未达账项）

企业和银行记账存在“时间差”，分四类：

| 类型 | 含义 | 调节方向（企业账面余额） |
| --- | --- | --- |
| 企业已收，银行未收 | 企业记了收款，银行还没到账 | 加 |
| 企业已付，银行未付 | 企业开了支票等，银行尚未兑付 | 减 |
| 银行已收，企业未收 | 银行收到款项，企业尚未入账 | 加 |
| 银行已付，企业未付 | 银行代扣等，企业尚未入账 | 减 |

**两个标准等式（教科书通用，非专有）：**

```
调节后企业余额 = 企业账面余额 + 银行已收企业未收 − 银行已付企业未付
调节后银行余额 = 银行对账单余额 + 企业已收银行未收 − 企业已付银行未付
```

调节后两者**必须相等**；不等说明记账有漏错，需回溯。

## 三、脱敏示例（示例数据，非真实口径）

| 项目 | 金额 |
| --- | --- |
| 企业银行存款账面余额 | 100,000 |
| 加：银行已收企业未收 | 5,000 |
| 减：银行已付企业未付 | 2,000 |
| **调节后企业余额** | **103,000** |
| 银行对账单余额 | 98,000 |
| 加：企业已收银行未收 | 8,000 |
| 减：企业已付银行未付 | 3,000 |
| **调节后银行余额** | **103,000** |

> 上表仅为演示“调节后双余额相等”的结构，数字随手编，不代表任何真实企业或风险标准。

## 四、现金盘点与“白条”通用说明

- **日清**：每日终了，保险柜实存现金 = 现金日记账余额。溢（长款）/ 缺（短款）都要查清原因。
- **白条抵库**：用不符合规定的借条 / 单据顶替库存现金，属于资金管理不规范，应清收或补办手续。
- 大额、长期白条、公私账户混用，都是资金风险信号，需引起警觉。

## 五、风险提示（通用原则，不含校准阈值）

以下为**通用关注点**，具体“红线数值 / 判定口径”属于付费闭源核心，不在本社区版给出：

- 货币资金长期畸高或畸低，与经营规模不匹配；
- 现金 long/short 款频繁，或长期挂白条；
- 公私账户混用、大额资金体外循环；
- 银行流水与企业账面长期对不平却未查明。
