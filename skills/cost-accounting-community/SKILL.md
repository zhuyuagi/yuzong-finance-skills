# 成本会计核算（社区版）

> 本文件是**开源讲解版**，只给“方法论 + 脱敏示例”，不提供校准过的风险阈值与全套出活模板。
> 需要可直接交付的分配表、约当产量表、产品成本计算单与标准成本差异分析，请使用 WorkBuddy 付费版。

## 一、成本核算在干什么（工作流）

目标：把企业一段时间的生产耗费，按产品 / 订单归集、分配，算出“单位成本”和“总生产成本”。

主线：要素费用 → 归集到成本对象 → 归集共同费用 → 分配 → 辅助生产分配 → 制造费用分配 → 在完工与在产品间分配 → 算出完工产品成本。

## 二、通用框架

### 1. 要素费用归集
按“直接材料 / 直接人工 / 制造费用”三大块，先把能直接追溯到产品的直接计入，不能直接追溯的先归进“共同费用”待分配。

### 2. 共同费用分配（通用公式）

```
分配率 = 待分配共同费用总额 ÷ 各对象分配标准合计
某对象应负担 = 该对象分配标准 × 分配率
```

分配标准可据情况选：工时、机器小时、产量、面积等（选什么标准属于方法判断，非专有）。

### 3. 辅助生产费用分配
供水、供电、维修等辅助车间费用，按受益对象分配（直接分配法 / 交互分配法等，方法选择非专有）。

### 4. 制造费用分配
车间层面不能直接计入产品的费用，按工时等标准分摊到各产品。

### 5. 在完工与在产品间分配（约当产量法，通用）

```
约当产量 = 在产品数量 × 完工程度（材料/工费可分别估算）
单位成本 = 本月生产费用合计 ÷ (完工产量 + 约当产量)
完工产品成本 = 完工产量 × 单位成本
```

### 6. 产品成本计算单
汇总上述结果，得出每种产品的“料 / 工 / 费”与总成本、单位成本。

### 7. 标准成本差异（通用概念）

```
总差异 = 实际成本 − 标准成本
价格差异 = (实际价格 − 标准价格) × 实际用量
用量差异 = (实际用量 − 标准用量) × 标准价格
```

差异正负代表有利 / 不利，需进一步追因（量差 / 价差来自采购、耗用、效率等环节）。

## 三、脱敏示例（示例数据，非真实口径）

- 待分配共同费用：12,000；分配标准合计（工时）：1,000
- 分配率 = 12,000 ÷ 1,000 = 12 / 工时
- A 产品耗用 600 工时 → 负担 7,200；B 产品 400 工时 → 负担 4,800

> 上例仅为演示“分配率 × 标准 = 应负担”的计算结构，数字随手编。

## 四、风险提示（通用原则，不含校准阈值）

- 分配标准选错会扭曲产品成本，影响定价与盈利判断；
- 在产品完工程度估不准，会虚增 / 虚减完工成本；
- 制造费用长期不分配或乱分配，是成本核算常见病；
- 标准成本差异“超阈”代表管控失灵——具体阈值与定性属于付费闭源核心。
